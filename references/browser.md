# Chrome / Edge 收藏初始化

使用宿主已有的浏览器连接器、浏览器工具或MCP。优先用户指定的Chrome或Edge，其次当前已连接且有B站登录态的浏览器；都可用而用户未指定时，优先现有B站标签，不为选浏览器增加一轮问卷。不要更换浏览器绕过账号读取授权。

## 从空白档案起步

1. 用户授权读取收藏后，列出浏览器和标签，选择准确的Chrome/Edge连接。未打开B站时可新建 `https://www.bilibili.com/`，从页面“收藏”进入当前账号；由真实导航链接得到UID，不能写死别人的账号。
2. 若未登录，说明当前无法读取收藏，用户可本人完成登录；不要读取浏览器配置/数据库、导出Cookie，或擅自安装扩展/启用远程调试。用户暂不登录时立即按反馈与公开候选继续。
3. 抽样收藏分类和默认夹前1–2页，必要时加一个相关分类；约30–80个可见条目通常足以发现方向。保留类别、UP和少量代表性证据即可，不保存完整私密收藏。
4. 收藏混有学习、睡前、待看等用途，不能全部当作下饭喜好。只形成有日期、来源和置信度的推测；不要推断敏感个人属性。将最小摘要写入profile.inferred_preferences，初始化方式/阶段写profile.onboarding，保留未知字段。
5. 以相关UP投稿页和针对性搜索发现候选，再核实5条详情。首组可包含少量收藏回捞，但标“可能看过”，不声称“未看”。

## 宿主适配

- **本环境 `mcp__cua_repl`**：先按工具首调用要求初始化并读最新API；Chrome/Edge都按用户选择绑定，不把本机tab ID、扩展ID、选择器当常量。只读DOM/AX可取可见标题、时长、UP和href；不得经evaluate调用隐藏内部对象、Cookie/localStorage或任意网络fetch。
- **其他浏览器工具**：使用其公开的列标签、打开、读取、搜索、关闭能力。接口名称可能不同，必须以宿主实际工具文档为准；skill不捆绑特定自动化SDK，也不自行安装浏览器控制程序。
- **没有账号浏览器能力**：只用用户反馈和公开搜索；注明本次未读取收藏。没有任何可靠检索能力则明确缺口，不能编候选。

B站页面可能先显示空壳再加载内容，操作后读取最新DOM/AX，必要时一次后续观察；不固定长睡眠或忙轮询。只核实少数最终候选，不为下饭筛选下载完整媒体/ASR。详情页/播放受限时换候选，不绕过验证码、付费或安全拦截。

每个**本任务新建的视频检查页，用完立即关闭**。原有用户标签若被导航则尽量恢复原地址，不关用户原有页面；只有用户明确要求打开播放的交付页才保留。检查不是完整看过，自动播放也不算用户watched。

## 验证边界

2026-10-23已验证Chrome登录态下收藏分类/分页、UP稿件及视频详情读取、检查页关闭。Edge列为工具适配路径，未完成真实Edge登录态验收；不得写成“双浏览器均实测通过”。任何宿主均需实际可用的浏览器/搜索能力，skill本身不能提供登录态。
